# Winter-of-Code-6
Winter of Code 6.0 (WOC 6.0) is a 3-month open-source program by GDG On Campus IIIT Kalyani. Explore real-world projects, collaborate with open-source organisations, learn from mentors, and make meaningful GitHub contributions. Inspired by Google Summer of Code (GSoC), WOC 6.0 welcomes beginners and experienced developers.
