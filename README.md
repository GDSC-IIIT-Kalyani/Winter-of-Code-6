## About

**Winter of Code 6.0 (WOC 6.0)** brings developers, designers, and tech enthusiasts together to contribute to real-world open-source projects. Explore participating organisations, work with experienced mentors, collaborate with the community, and build practical development experience.

Inspired by the contribution-driven spirit of **Google Summer of Code (GSoC)**, WOC welcomes both first-time contributors and experienced developers. Learn by exploring codebases, fixing issues, building features, and submitting pull requests.

## Get started

1. **Register:** [Apply through Devfolio](https://woc6.devfolio.co/).
2. **Explore:** Browse organisations and projects on the [WOC website](https://www.winter-of-code-6.tech/).
3. **Contribute:** Choose projects, submit proposals, collaborate with mentors, and start building.
